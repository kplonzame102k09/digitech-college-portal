Prototype Security Notice

This portal uses browser LocalStorage only. It is a front-end prototype and must not be used for real passwords or sensitive student data. A production system would require backend authentication, server-side authorization, secure hashing, a database, HTTPS, validation, proper file storage, and security controls.
